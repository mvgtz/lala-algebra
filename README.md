# Lala's Math
Buildless, browser-local Algebra 1 practice. Serve index.html and app.js together.

15 daily base questions: 8 weekly-focus, 4 rotating review, 3 from previously missed skills. Wrong answers require a targeted skill question and a fresh retest before progress. Extra questions do not count toward 15. State saves on every transition in localStorage. A refresh retains the remediation gate. No backend, analytics, account, or automatic teacher access. Reports download as text or print to PDF. Clearing browser data removes results. This is practice, not a secure examination system.

Six-week repeating review schedule and editable start date. Unit 1.4 alignment: two/multi-step inequalities, negative and fractional coefficients, endpoints/graph descriptions, compound AND/OR, modeling/viability. Broader strands offer representative review, not exhaustive curriculum coverage.
