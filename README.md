# Lala's Math
Buildless, browser-local Algebra 1 practice. Serve index.html and app.js together.

## Daily practice
15 base questions: 8 current CRM 1.4 inequalities, 4 rotating earlier-unit review, 3 drawn from previously missed covered skills. Wrong answers require targeted practice and a fresh retest of the original subtopic before progress. Extras do not count toward 15. The retry gate saves on every transition, including refresh. First-attempt scores stay separate from extra practice.

## Curriculum update
Aligned to the supplied October materials, using original questions and numbers:
- Equations: signed numbers, fractions, distribution, variables on both sides, absolute value with two/one/no solutions, contextual equations.
- Linear-function features: function notation, tables, slope, intercepts, vertical transformations, continuous domain/range, whole-number constraints, comparing functions, reading coordinate graphs.
- CRM 1.3 / writing lines: literal equations, rearranging forms, point-slope, table-based equations, parallel/perpendicular lines, horizontal/vertical exceptions, models.
- CRM 1.4 / inequalities: multi-step and fractional inequalities, reversal, compound AND/OR and negative coefficients, number-line interpretation, viable counts, two-variable boundaries/shading, reading coordinate graphs, vertical boundaries, standard-form rearranging, testing points, budgets.

44 question generators total; 37 covered strands assigned in this plan. Broader generators (systems, exponent rules, polynomials, factoring, quadratics, radicals, data) are retained for compatibility with earlier saved progress but not assigned in the updated curriculum. Representative review, not a claim of exhaustive assessment of every slide or independent mastery. Existing started daily sets are retained; untouched sets use the new curriculum. Duplicate PDFs are not double-weighted. Source PDFs and answer keys are not published.

## Results and Monday reports
No backend, analytics, accounts, or automatic teacher access. localStorage stays in the same browser/device; clearing it removes results. Reports download as text or print to PDF. Monday reminders cover the previous Monday–Sunday and remain visible if overdue until downloaded. Downloading never claims to send a report. App must be opened to see reminders. Reports include inferred error totals and individual attempts, including graph descriptions. An exported weekly report can be downloaded again under Results. This is practice, not a secure exam system.

## Hosting and tests
GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
No build dependencies. Test with `node test.cjs`; tests cover generated choices, numerical equation/inequality equivalence, required retries, fresh subtopics, saved progress, schedule coverage, date boundaries, and weekly filtering.
